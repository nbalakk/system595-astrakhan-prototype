# Центр здоровья и долголетия в Астрахани — прототип

Статический адаптивный прототип центра здоровья и долголетия для пенсионеров: забота о здоровье и стремление сохранять активность с возрастом, знакомство с оборудованием системы 5/95 в центре и выбор аппарата для дома. Это цели посетителей, а не обещание результата от оборудования. Название описывает направление центра; официальное имя и остальные неподтверждённые данные требуют согласования. Реальные заявки не принимаются.

## Просмотр

Требуется Node.js 20 или новее. Дополнительные пакеты не нужны.

```powershell
node scripts/build.mjs
node scripts/serve.mjs
```

Открыть http://127.0.0.1:5950/ . Проверка размещения в подпапке: http://127.0.0.1:5950/prototype/ .

```powershell
node scripts/check.mjs
node --test scripts/display.test.mjs scripts/booking.test.mjs scripts/positioning.test.mjs
```

## Что входит

16 страниц: главная, посещения центра, каталог, шесть аппаратов, отзывы, полезные материалы, статья-памятка, контакты, демонстрационная запись, источники изображений и пояснение о форме. Прежний адрес `/rehabilitation/` сохранён для совместимости ссылок; страница называется «Посещения центра».

Главная ведёт от первого визита к посещениям центра и, при интересе, к покупке аппарата для дома. Подробная показательная модель — BodyHealth: устройство, управление и функции по официальным материалам System 5/95 и NovuMedical. FootSystem сохранён отдельной карточкой; тождественность двух названий не предполагается.

Сайт работает без сервера приложений, внешних шрифтов и аналитики. Поля формы не сохраняются и не отправляются. Браузер запоминает только настройки отображения. Все пути относительные. Форма по умолчанию заблокирована, пока не установлен обработчик, который предотвращает отправку.

## Обычный и увеличенный вид

Обычная версия использует компактную шапку, основной текст 17–18 px и заголовки 33–48 px. В шапке всех страниц доступна кнопка «Версия для слабовидящих».

В увеличенном режиме доступны три размера текста (22, 26 и 30 px), чёрный текст на белом фоне или белый на чёрном. Настройки восстанавливаются до показа страницы. Панель выбора раскрывается при включении режима, а на следующей странице остаётся свёрнутой. Кнопка «Обычная версия» возвращает исходное оформление.

Используется один ключ `centre595.display` и строго три поля: `enabled`, `size`, `theme`. Ошибки хранилища не блокируют сайт. Имя и телефон к этому механизму не имеют доступа.

## Размещение на GitHub Pages

1. Создать репозиторий для этого прототипа и загрузить подготовленную ветку `main`.
2. В Settings → Pages → Build and deployment выбрать **GitHub Actions**.
3. Запустить **Publish prototype to GitHub Pages** на вкладке Actions или отправить изменение в `main`.

Workflow собирает и проверяет сайт, затем публикует только содержимое `dist`. Внутренние материалы проекта, история чата и локальные файлы проверки в публикацию не входят. Бесплатный GitHub Pages обычно требует публичный репозиторий; точные условия зависят от аккаунта.

До реального запуска оставить запрет индексации: он задан через meta robots и robots.txt. Контакты, ассортимент и условия должны быть подтверждены, а форма подключена отдельно.

## Редактирование

- `site/content.mjs` — централизованные данные центра, демонстрационная линейка и ответы на вопросы.
- `site/pages.mjs` — содержимое страниц.
- `site/home.mjs`, `site/rehabilitation.mjs`, `site/bodyhealth.mjs` — три подробно проработанные страницы.
- `site/components.mjs` — общая навигация, подвал и форма.
- `site/styles.css` — дизайн и мобильные правила.
- `site/refinement.css`, `site/bodyhealth.css`, `site/landing.css` — стили доработанных страниц и красно-белого лендинга; сборка объединяет их в один файл.
- `site/display.js`, `site/display.css` — отдельный режим для слабовидящих и настройки отображения.
- `scripts/display.test.mjs` — проверки нормализации, сохранения настроек и приватности.
- `scripts/booking.test.mjs` — проверки целей обращения, выбранной модели, истории переходов и демонстрационной формы.
- `scripts/positioning.test.mjs` — сборка и проверка названия, позиционирования, метаданных и доступных подписей на всех 16 страницах.
- `site/app.js` — меню, фильтры, галерея, демонстрационная форма.
- `scripts/build.mjs` — сборка с явным списком разрешённых ресурсов.
