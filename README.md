# Центр здоровья и долголетия в Астрахани

Статический сайт для людей старшего возраста и их близких. Он помогает представить первое посещение, познакомиться с консультантом Светланой Бабак, договориться о времени по телефону и найти центр на карте. Система 5/95 представлена в справочном разделе об аппаратах.

## Просмотр и проверка

Требуется Node.js 20 или новее. Дополнительные пакеты не нужны.

```powershell
node scripts/build.mjs
node --test scripts/display.test.mjs scripts/booking.test.mjs scripts/positioning.test.mjs
node scripts/check.mjs
node scripts/serve.mjs
```

Сервер открывает [главную](http://127.0.0.1:5950/) и [копию в подпапке](http://127.0.0.1:5950/prototype/) для проверки относительных ссылок.

## Страницы и данные

- Сохраняются все 16 адресов предыдущей версии, включая страницы отдельных аппаратов. На отдельной странице размещён фильм о пяти шагах программы с русскими субтитрами и переходом к каждому шагу. Адрес записи со старыми параметрами открывает ту же памятку о звонке.
- Телефон и карта доступны сразу, в том числе без JavaScript. Сайт не собирает заявки. Браузер может запомнить только включение версии для слабовидящих, размер шрифта и контрастную схему в ключе `centre595.display`.
- Тексты и контактные данные находятся в `site/content.mjs`, страницы в `site/*.mjs`. Источники местных материалов и иллюстраций производителя указаны на странице «Фото и видео».
- Восемь редакционных материалов для раздела `/articles/` хранятся в `site/articles.json` в UTF-8. В каждой записи указаны адрес страницы, заголовок, краткое описание, рубрика, разделы и ссылки на источники. Сборщик создаёт статические страницы и оглавление по рубрикам. Памятка остаётся по адресу `/articles/first-visit/`.
- На главной показана группа на разминке из фототеки Centre for Ageing Better. Под фотографией указан источник. Прежняя запись занятия в астраханском центре доступна на самой главной с видимой обложкой, кнопкой просмотра и прямой ссылкой на оригинал. В разделе статей практические памятки дополнены архивом из семи публикаций центра.
- Встречу согласуют по телефону. Оба номера указаны в [публикации центра](https://ok.ru/profile/583466162659/statuses/157577238805987). Карта использует поиск по адресу. Часы работы уточняют при звонке.
- Сведения об Ассоциации и устройстве BodyHealth даны по материалам [NovuMedical](https://novumedical.org/o-nas/) и [описанию модели](https://novumedical.org/products/bodyhealth/). Документы привязывают к конкретной модели после проверки. Занятие и отзыв посетительницы опубликованы самим центром. Плеер Одноклассников загружается после нажатия. В сборку включают только подготовленный для сайта монтаж фильма о пяти шагах.
- Шрифт Golos Text распространяется по лицензии SIL Open Font License. Текст лицензии в `site/assets/OFL.txt`.

## Публикация

Изменение ветки `main` запускает проверку, сборку и публикацию `dist/` на [GitHub Pages](https://nbalakk.github.io/system595-astrakhan-prototype/). Публикуемые изображения перечислены в сборщике. В прототипе сохранён запрет индексации через meta robots и robots.txt.
